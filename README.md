# Mage Mana Gem

A simple World of Warcraft addon for Mages that deletes your depleted Mana Emerald so you can conjure a fresh one.

## Usage

Type `/delgem` in chat to delete your depleted Mana Emerald.

### Recommended Macro

Create a macro with the following lines to automatically delete your depleted gem before conjuring a new one:

```
#showtooltip Conjure Mana Emerald
/delgem
/cast Conjure Mana Emerald
```

## Installation

1. Download the latest release.
2. Extract the `MageManaGem` folder into your World of Warcraft `Interface/AddOns` directory.
3. Restart the game or reload your UI.

## Notes

- The addon will not delete items while you are in combat.
- Supports English, French, Spanish, and German client locales.
